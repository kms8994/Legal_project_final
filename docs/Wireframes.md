# CaseLens 핵심 화면 와이어프레임

## 1. 목적

이 문서는 MVP에서 반드시 구현할 핵심 화면 4개의 구조와 사용자 흐름을 고정한다. 첫 구현은 장식적인 랜딩 페이지가 아니라 검색에서 비교까지 바로 이어지는 도구 화면을 기준으로 한다.

## 2. 공통 UI 원칙

- 첫 화면에서 바로 검색할 수 있어야 한다.
- 모든 AI 요약에는 `원문 확인 필요` 배지를 표시한다.
- 법령정보센터 API는 런타임에 호출하지 않는다는 데이터 기준일 고지를 하단에 표시한다.
- 결과 차이는 강조하되, 비교 후보 정렬은 사실관계와 material facts 유사도를 우선한다.
- 모바일에서는 2열 비교를 세로 스택 또는 탭으로 전환한다.

## 3. 화면 1: 검색 시작

경로: `/`

목표: 사용자가 조문, 자연어 사건 설명, 사건번호 중 하나로 바로 검색을 시작한다.

```text
┌─────────────────────────────────────────────────────────────┐
│ CaseLens                                                    │
│ 손해배상 판례를 검색하고 비교합니다                         │
├─────────────────────────────────────────────────────────────┤
│ [조문] [자연어] [사건번호]                                  │
│                                                             │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │ 민법 제750조                                            │ │
│ └─────────────────────────────────────────────────────────┘ │
│                                      [검색]                 │
│                                                             │
│ 데이터 기준일: YYYY-MM-DD · AI 요약은 참고용입니다          │
└─────────────────────────────────────────────────────────────┘
```

필수 상태:

- 조문 모드 placeholder: `민법 제750조`
- 자연어 모드 placeholder: `교통사고 피해자의 과실상계가 문제된 손해배상 판례`
- 사건번호 모드 placeholder: `2021다12345`
- 검색 중 loading state
- 조문 파싱 실패 시 입력 예시와 후보 법령 표시

주요 행동:

- 검색 버튼 클릭 또는 Enter 입력 시 `/search?mode=&q=`로 이동한다.
- 검색어는 URL query에 보존한다.

## 4. 화면 2: 검색 결과

경로: `/search`

목표: 관련 판례를 카드로 보여주고 기준 판례 선택을 유도한다.

```text
┌─────────────────────────────────────────────────────────────┐
│ 검색어: 민법 제750조                         [검색 수정]    │
├─────────────────────────────────────────────────────────────┤
│ 자연어 검색일 때만 표시                                     │
│ ┌ 이렇게 이해했어요 ──────────────────────────────────────┐ │
│ │ 손해배상 · 교통사고 · 과실상계 · 민법 제750조            │ │
│ └─────────────────────────────────────────────────────────┘ │
│                                                             │
│ ┌ 판례 카드 ──────────────────────────────────────────────┐ │
│ │ 대법원 · 2022-03-15 · 2021다12345                       │ │
│ │ 손해배상                                                │ │
│ │ [원문 확인 필요] 사실관계 요약 2~3줄                    │ │
│ │ 주요 조문: 민법 제750조, 민법 제396조                   │ │
│ │ 결과: 원고 일부 유리 · 핵심 요소: 피해자 과실           │ │
│ │ [원문 근거 보기] [기준 판례로 선택]                     │ │
│ └─────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

필수 상태:

- 결과 없음: 조건 완화 제안과 자연어 검색 전환 버튼
- 자연어 confidence 낮음: 추가 사실 입력 요청 1개
- 카드 skeleton loading
- 원문 링크 또는 원문 근거 모달

주요 행동:

- `기준 판례로 선택` 클릭 시 `/cases/{caseId}/compare`로 이동한다.
- `원문 근거 보기` 클릭 시 판례 상세 또는 근거 문단 위치로 이동한다.

## 5. 화면 3: 비교 후보

경로: `/cases/{caseId}/compare`

목표: 기준 판례와 사실관계가 유사한 비교 후보 Top 5를 추천한다.

```text
┌─────────────────────────────────────────────────────────────┐
│ 기준 판례                                                   │
│ 대법원 · 2022-03-15 · 2021다12345                           │
│ [원문 확인 필요] 기준 판례 요약                              │
├─────────────────────────────────────────────────────────────┤
│ 비교 후보 Top 5                                             │
│                                                             │
│ ┌ 후보 카드 ──────────────────────────────────────────────┐ │
│ │ 사실관계 유사도 높음 · material facts 4/6 일치           │ │
│ │ 공통 사실: 차량 대 보행자 사고, 피해자 과실 다툼         │ │
│ │ 미세 차이 가능성: 무단횡단 인정 여부                     │ │
│ │ 결과 차이: 기준은 일부 인용, 후보는 과실상계 감액        │ │
│ │ 완화 단계: 없음                                         │ │
│ │ [비교하기] [관련 없음]                                  │ │
│ └─────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

필수 상태:

- 후보 부족: 완화 단계와 이유 표시
- outcome 차이는 있으나 사실관계 유사도가 낮은 후보: 낮은 우선순위로 표시
- 추천 이유 loading/fallback
- 관련 없음 피드백 저장

주요 행동:

- `비교하기` 클릭 시 `/compare?base={baseId}&target={targetId}`로 이동한다.
- `관련 없음` 클릭 시 간단 피드백을 저장한다.

## 6. 화면 4: 판례 비교 분석

경로: `/compare?base=&target=`

목표: 두 판례의 공통점, 미세 차이, 결과 차이를 근거 문단과 함께 보여준다.

```text
┌─────────────────────────────────────────────────────────────┐
│ 기준 판례                              비교 판례            │
│ 2021다12345                            2020다54321          │
├─────────────────────────────────────────────────────────────┤
│ 공통 사실관계                                               │
│ - 차량 대 보행자 사고 [p12][p08]                            │
│ - 손해배상 범위와 과실상계가 문제됨 [p18][p14]              │
├─────────────────────────────────────────────────────────────┤
│ 핵심 미세 차이                                              │
│ 1. 피해자 행위                                              │
│    기준: 과실 낮게 인정 [p21]                               │
│    비교: 무단횡단 인정 [p17]                                │
│    의미: 과실상계 비율 차이 가능성                          │
├─────────────────────────────────────────────────────────────┤
│ 결과 차이                                                   │
│ 기준: 일부 인용 · 비교: 과실상계로 감액                     │
├─────────────────────────────────────────────────────────────┤
│ 원문 근거 문단                                              │
│ [p12] ...                                                   │
│ [p17] ...                                                   │
│                                                             │
│ [관련 있음] [근거 부족] [요약 오류]                         │
└─────────────────────────────────────────────────────────────┘
```

필수 상태:

- LLM timeout: 구조화 표 기반 fallback 표시
- evidence 부족: `원문 근거 부족` 배지 표시
- 검수 전 구조화 결과: `검수 전 요약` 배지 표시
- 모바일: 기준/비교 탭과 세로형 비교 카드

주요 행동:

- evidence id 클릭 시 근거 문단으로 스크롤한다.
- 피드백 버튼 클릭 시 label과 선택 판례 id를 저장한다.

## 7. 3클릭 MVP 흐름

```text
1. 검색 시작 화면에서 검색
2. 검색 결과에서 기준 판례 선택
3. 비교 후보에서 비교하기
```

3번째 클릭 후 비교 분석 화면이 표시되어야 한다.

## 8. 구현 완료 체크리스트

- [ ] 검색 시작 화면에서 바로 검색할 수 있다.
- [ ] 검색 결과 카드에서 기준 판례를 선택할 수 있다.
- [ ] 비교 후보 카드에 추천 이유와 완화 단계가 표시된다.
- [ ] 비교 분석에 공통 사실, 미세 차이, 결과 차이, evidence id가 표시된다.
- [ ] LLM 실패 시 fallback 화면이 표시된다.
- [ ] 모바일에서 비교 화면이 세로형 또는 탭형으로 전환된다.
