# MVP 조문 범위와 수집 우선순위

## 1. 목표

MVP에서는 손해배상 도메인에 집중한다. 조문 수를 과하게 늘리지 않고, 사실관계 비교와 결과 차이 설명에 적합한 조문부터 수집한다.

## 5. 수집 키워드

조문 검색과 함께 다음 키워드를 사용해 보완 수집한다.

- 교통사고
- 과실상계
- 위자료
- 불법행위
- 공동불법행위
- 사용자책임
- 손해배상 범위
- 인과관계
- 피해자 과실
- 자동차손해배상

## 6. MVP 수집 목표

```text
P0 조문 기준 최소 300건
P1 포함 시 최대 500건
중복률 3% 이하
구조화 가능 판례 70% 이상
```

## 7. 수집 후 검토 기준

각 조문별로 다음을 기록한다.

- 수집 판례 수
- 중복 제거 후 판례 수
- 원문 확보율
- 문단 분리 성공률
- cited_articles 추출 성공률
- material_facts 구조화 성공률
- 비교 후보 생성 가능성

## 8. API 사용 정책

법령정보센터 API는 로컬/배치 수집 용도로만 사용한다.

```text
법령정보센터 API
→ collect_laws / collect_cases
→ 내부 PostgreSQL 저장
→ 런타임 백엔드는 내부 DB만 조회
```

이 정책의 이유:

- 검색 응답 속도를 외부 API 상태에 의존하지 않기 위해
- 동일 조문/판례를 반복 호출하지 않기 위해
- 구조화, 임베딩, 평가를 내부 데이터 기준으로 안정화하기 위해
- API 장애 시에도 기존 검색 서비스를 유지하기 위해

## 9. 제외 기준

다음 판례는 MVP 검색 결과 노출 우선순위를 낮춘다.

- 원문 근거가 부족한 판례
- facts 구조화가 불가능한 판례
- outcome direction이 unknown인 판례
- 손해배상 도메인과 관련이 약한 판례
- 사건번호 또는 선고일이 불명확한 판례
