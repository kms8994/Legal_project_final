# 법률/저작권/개인정보 정책

## 1. 서비스 성격

CaseLens는 법률 정보 탐색과 판례 비교 학습을 위한 참고 도구다. 법률 자문, 승소 가능성 예측, 실제 사건 대응 지시를 제공하지 않는다.

## 2. 필수 고지 문구

```text
CaseLens의 검색 결과, AI 요약, 판례 비교 분석은 참고용 정보입니다.
법률적 판단이나 실제 사건 대응은 반드시 판례 원문, 최신 법령, 전문가 검토를 통해 확인해야 합니다.
본 서비스는 판례 데이터 누락, AI 요약 오류, 법령 개정 미반영 가능성을 포함합니다.
```

## 3. 원문 표시 정책

MVP 원칙:

- 판례 원문 전체를 사용자 화면에서 대체 제공하지 않는다.
- 공식 원문 링크를 우선 제공한다.
- AI 요약과 비교 설명은 원문 근거 문단 일부와 함께 제공한다.
- 원문 근거 문단은 필요한 범위에서만 표시한다.
- 원문 근거가 부족하면 `원문 근거 부족`으로 표시한다.

## 4. AI 요약 정책

- AI 요약은 참고용이다.
- 요약에는 원문 확인 필요 배지를 붙인다.
- evidence span이 없는 요약은 사용자에게 노출하지 않는다.
- LLM이 생성한 조문, 판례번호, 금액, 비율은 검증 후 사용한다.

## 5. 개인정보 정책

MVP에서 저장 가능한 사용자 데이터:

- 검색어
- 검색 유형
- 검색 시각
- 결과 클릭/비교 선택
- 피드백 라벨

주의:

- 자연어 검색어에는 개인정보나 민감정보가 포함될 수 있다.
- MVP에서는 검색 로그 보존 기간을 90일로 둔다.
- 향후 개인정보 마스킹 파이프라인을 추가한다.

## 6. 금지 기능

- 승소 가능성 수치화
- 실제 사건에 대한 법률 결론 단정
- 변호사 상담 대체 표현
- 원문 근거 없는 법령/판례 생성
- 최신 법령 확인 없이 현재 법률 상태 단정

## 7. UI 표시 위치

| 위치 | 표시 |
|------|------|
| 첫 화면 하단 | 짧은 면책 고지 |
| 결과 카드 | AI 요약, 원문 확인 필요 배지 |
| 비교 분석 하단 | 고지 전문 |
| 원문 링크 옆 | 공식 출처 확인 버튼 |
| 피드백 UI | 오류 신고 가능 |

## 8. 배포 전 체크리스트

- [ ] 공식 원문 링크가 제공된다.
- [ ] 원문 전체 대체 노출이 없다.
- [ ] AI 요약에 근거 문단이 연결된다.
- [ ] 법률 자문 아님 고지가 표시된다.
- [ ] 검색 로그 보존 기간이 문서화되어 있다.
- [ ] 개인정보 포함 가능성 안내가 있다.
